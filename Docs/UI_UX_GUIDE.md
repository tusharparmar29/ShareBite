# ShareBite – UI/UX Guide

## Direction
Clean, modern, community-focused, trustworthy and easy to demo.

## Layout
Desktop: dashboard sidebar + content area.
Mobile: responsive navigation and stacked cards.

## Status
AVAILABLE, CLAIMED, COMPLETED, EXPIRED, CANCELLED.
Always show text; do not depend on color alone.

## Priority
Normal, High, Urgent.
Show numeric score only when useful.

## Expiry
Fresh, Pickup Soon, Expired.

## Donation Form
1. Food information
2. Quantity
3. Preparation/storage
4. Pickup details
5. Optional image

## Loading
Prefer local skeletons/spinners for affected content. Avoid full-screen loading for small requests.

## Accessibility
Use semantic HTML, labels, keyboard-friendly controls, readable text and sufficient contrast.
